# PROG5121 Chat App - Part 1

Registration and login feature for the Chat App PoE.

## Overview

This console application allows a user to register with a username, password,
and South African cell phone number, then log in using the same credentials.

## Features

- **Username validation** — must contain an underscore (`_`) and be no more than 5 characters.
- **Password complexity** — at least 8 characters, one capital letter, one number, and one special character.
- **SA cell phone validation** — must use the international country code `+27` followed by 9 digits.
- **Login authentication** — verifies entered credentials against stored registration details.
